## Assignment 3 — Text Viewport Manager
the program demonstrates:

- 80 × 25 text-mode screen initialization
- Double-line bordered viewport
- Text output using string instructions
- Scrolling within window boundaries
- Keyword searching and highlighting
- Match counting and status display
- Stack-based subroutines
